\# Automated Books Analytics Pipeline



\## Overview

A Python automation project that fetches book data, cleans it, analyzes prices, and generates reports automatically.



\## Features

\- Automated data fetching

\- Data cleaning and duplicate removal

\- Price analysis

\- CSV and JSON report generation

\- Price distribution chart

\- Rotating logs

\- Pytest testing

\- Windows Task Scheduler automation



\## Technologies

\- Python

\- Requests

\- BeautifulSoup

\- Pandas

\- Matplotlib

\- Pytest



\## Run Project

```bash

pip install -r requirements.txt

python main.py

```



\## Output

\- output/books.csv

\- output/report.json

\- output/price\_chart.png

\- logs/pipeline.log
